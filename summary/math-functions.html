Ordered pairs and the Cartesian product

An ordered pair (a, b) has a first element a and a second element b, and the order matters: (a, b) = (c, d) only if a = c and b = d. That is the difference from a set, where {2, 5} = {5, 2} but (2, 5) ≠ (5, 2).

The Cartesian product A × B is the set of all ordered pairs (a, b) with a ∈ A and b ∈ B, and n(A × B) = n(A) · n(B).

GivenA × Bn(A × B)
A = {1, 2}, B = {x, y}{(1,x), (1,y), (2,x), (2,y)}2 × 2 = 4
A = {a}, B = {1, 2, 3}{(a,1), (a,2), (a,3)}1 × 3 = 3
A = ∅, B = {1, 2}∅0 × 2 = 0

A × B ≠ B × A in general, because (a, b) and (b, a) differ when a ≠ b. The product is equal both ways only when A = B or one set is empty.

Relations (ความสัมพันธ์)

Definition. A relation R from A to B is any subset of A × B, so R ⊆ A × B. It pairs some elements of A with some of B, with no limit on how many outputs an input may have.

TermDefinitionFor R = {(1,x), (2,y)}, B = {x, y, z}
Domainall first elements actually used{1, 2}
Rangeall second elements actually used{x, y}
Co-domainthe whole set B, used or not (range ⊆ co-domain){x, y, z}; z is unused

A relation can be shown as a set of pairs, a table, an arrow diagram or a graph. Every subset of A × B counts, even ∅ and A × B itself.

Functions (ฟังก์ชัน)

Definition. A function f : A → B is a relation where every element of A is paired with exactly one element of B. Two conditions: (1) every element of A appears as a first element, and (2) no element of A has two different outputs.

Vertical line test

A curve is the graph of a function exactly when every vertical line meets it at most once. If a vertical line crosses twice, one x has two y-values. Slide the grey vertical line in Fig. 2 and read how many times it meets the graph.

Python functions are mathematical functions

A def block takes one input and returns one output. Composition becomes nested calls, and f(g(x)) differs from g(f(x)).

def f(x): return 2*x + 1
def g(x): return x**2
fog = lambda x: f(g(x))     # (f∘g)(x)
gof = lambda x: g(f(x))     # (g∘f)(x)
print(fog(3), gof(3), fog(3) == gof(3))   # 19 49 False

Function operations and composition

OperationNotationFormulaDomain
Sum(f + g)(x)f(x) + g(x)Df ∩ Dg
Difference(f − g)(x)f(x) − g(x)Df ∩ Dg
Product(f · g)(x)f(x) · g(x)Df ∩ Dg
Quotient(f / g)(x)f(x) / g(x)Df ∩ Dg, with g(x) ≠ 0
Composition(f ∘ g)(x)f(g(x)){x ∈ Dg : g(x) ∈ Df}

Composition (f ∘ g)(x) = f(g(x)) applies g first, then feeds the result to f: read it "f after g". And f ∘ g ≠ g ∘ f in general. Pick any f and g in Fig. 3 and compare the two lanes.

Example with f(x) = 2x + 1 and g(x) = x²: (f ∘ g)(x) = f(x²) = 2x² + 1, but (g ∘ f)(x) = (2x + 1)² = 4x² + 4x + 1, so the order matters.

Inverse functions (ฟังก์ชันผกผัน)

The inverse f⁻¹ exists if and only if f is bijective. It reverses the mapping: if f(a) = b then f⁻¹(b) = a. To find it: (1) write y = f(x), (2) swap x and y, (3) solve for y, (4) rename y as f⁻¹(x).

PropertyStatement
Domain and range swapdomain of f⁻¹ = range of f; range of f⁻¹ = domain of f
Cancelling(f ∘ f⁻¹)(x) = x and (f⁻¹ ∘ f)(x) = x
Graphf and f⁻¹ are mirror images across the line y = x
Notationf⁻¹(x) is the inverse, not 1 / f(x)

Worked example f(x) = 3x − 2: y = 3x − 2; swap: x = 3y − 2; solve: y = (x + 2)/3; so f⁻¹(x) = (x + 2)/3. Check: f(f⁻¹(x)) = 3·(x + 2)/3 − 2 = x ✓. For x² to have an inverse it must be restricted to x ≥ 0, then f⁻¹ = √x (choose it in Fig. 4).

SAT: how many solutions?

A favourite SAT question asks how many solutions an equation has, or what value of a constant gives exactly one, none or infinitely many. Every case is a question about where two graphs meet, so the counts are limited by what the graph can do.

Equation typePossible numbers of solutionsWhat decides it
Linear: ax + b = cx + d0, 1 or infinitely manyslopes a and c, then the intercepts
Quadratic: ax² + bx + c = 00, 1 or 2the discriminant b² − 4ac
Line and parabola0, 1 or 2set equal and use the discriminant; tangent means 1
Exponential: a·bˣ = k0 or 1 (never 2)sign of k/a, and b ≠ 1
Absolute value: |ax + b| = k0, 1 or 2sign of k (k = 0 gives one)
Radical: √(px + q) = x + r0, 1 or 2squaring, then checking each root

Linear: one, none or infinite

Solve ax + b = cx + d by collecting x: (a − c)x = d − b. If a ≠ c there is exactly one solution. If a = c the x terms cancel: then b = d gives a statement that is always true (infinitely many) and b ≠ d gives one that is never true (no solution). Geometrically these are two lines: different slopes cross once, equal slopes with different intercepts are parallel, and equal slopes with equal intercepts are the same line. That is exactly the parallel and coincident rows of Parallel and perpendicular lines in Analytic Geometry. Make a equal to c in Fig. 5 and then make b equal to d.

SAT shortcut: "For what value of k does 3x + 5 = kx + 5 have infinitely many solutions?" Matching slopes and intercepts gives k = 3. "…no solution?" would need k = 3 but a different constant on one side.

Quadratic: the discriminant

For ax² + bx + c = 0, the discriminant D = b² − 4ac, the expression under the root in the quadratic formula, counts the real solutions. D > 0: two. D = 0: one repeated root, and the vertex sits on the x-axis. D < 0: none, the parabola misses the axis. Useful extras: the roots add to −b/a and multiply to c/a, and the vertex is at x = −b/(2a).

A line meeting a parabola works the same way: set the two expressions equal to get a quadratic, then read its discriminant. D > 0 means the line cuts twice, D = 0 means it is tangent, and D < 0 means it misses.

Quadratic formLooks likeShows you directly
Standardy = ax² + bx + cthe y-intercept c and the direction (sign of a)
Factoredy = a(x − r₁)(x − r₂)the zeros r₁ and r₂
Vertexy = a(x − h)² + kthe vertex (h, k), and the minimum or maximum

Exponential: at most one

The graph of y = a·bˣ (with a > 0, b > 0, b ≠ 1) is always above the x-axis and always rising (b > 1, growth) or always falling (0 < b < 1, decay), so a horizontal line y = k can meet it only once. If k/a > 0 the single answer is x = logb(k/a); if k ≤ 0 there is no solution, because the x-axis is an asymptote that is never reached. Compare this with the quadratic: a parabola turns around, an exponential never does. The SAT model for growth is y = a(1 + r)ᵗ and for decay y = a(1 − r)ᵗ.

Where a and b come from: percent change

Write an exponential as y = a·bˣ (the SAT often writes y = a(1 + r)ˣ). Here a is the initial amount, the value when x = 0 and the point where the curve crosses the y-axis. b is the growth factor, the number you multiply by at every step. If a quantity rises by r percent each step then b = 1 + r, so +5% means b = 1.05. If it falls by r percent then b = 1 − r, so −20% means b = 0.8. Example: $200 growing 5% a year is y = 200(1.05)ˣ, and after 3 years it is 200 × 1.05³ ≈ 231.5. Change b in Fig. 7 and read off the "change per step".

The SAT likes to test this against a fixed top-up, where the same amount is added each time instead of the same percentage:
