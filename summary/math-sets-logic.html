What is a set?

Definition. A set is a well-defined collection of distinct objects called elements. Sets are named with capital letters. x ∈ A means x belongs to A; x ∉ A means it does not. The number of elements is n(A).

Two sets are equal when they contain exactly the same elements, whatever the order or repetition, so {1, 2, 3} = {3, 1, 2}. There are two ways to write a set:

NotationExampleBest when
Roster: list every element inside braces{2, 4, 6, 8, 10}the set is small or finite
Set-builder: state the membership rule after the bar |{ x | x is even, 1 ≤ x ≤ 10 }the set is large or infinite

For example A = {1, 2, 3, 4, 5} has n(A) = 5, and C = { x ∈ ℝ | x² = 4 } = {−2, 2} has n(C) = 2.

Subsets and proper subsets

Subset A ⊆ Bevery element of A is also in B. This includes A = B, so A ⊆ A is always true.
Proper subset A ⊂ BA ⊆ B and A ≠ B, so B has at least one element A lacks. A is never a proper subset of itself.

If n(A) = n, the number of subsets follows a power-of-two rule:

CountFormulaExample n = 3
All subsets (∅ and A included)2ⁿ2³ = 8
Proper subsets (A excluded)2ⁿ − 12³ − 1 = 7

Two edge cases catch many students. ∅ ⊆ A is always true, because the empty set has no element that could fail to be in A. And {∅} ≠ ∅: {∅} contains one member (the empty set), so n({∅}) = 1.

Power set 𝒫(A)

The power set 𝒫(A) is the set of all subsets of A, including ∅ and A. It is also written P(A) or 2A, and n(𝒫(A)) = 2n(A). Special case: 𝒫(∅) = {∅}, with n = 2⁰ = 1. Build one yourself in Fig. 1: raise n(A) and watch the count double each time.

For A = {1, 2}: 𝒫(A) = {∅, {1}, {2}, {1,2}}, so 4 elements. For B = {a, b, c}: 8 elements, namely ∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}.

In Fig. 2 set the sizes and see every region. The overlap n(A ∩ B) is subtracted once in the union formula because adding n(A) and n(B) counts it twice.

Worked example with A = {1,2,3,4}, B = {3,4,5,6}, U = {1,…,7}: A ∪ B = {1,2,3,4,5,6}; A ∩ B = {3,4}; A′ = {5,6,7}; A − B = {1,2}; n(A × B) = 4 × 4 = 16 ordered pairs.

Inclusion–exclusion principle

The formulas below count a union without counting any overlap twice. For three sets the triple overlap is added back because it was added three times, then subtracted three times with the pairs, so it vanished completely. Use Fig. 3 to see this; the defaults are the class example below.

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)two sets: the shared part is counted twice, so subtract it once
n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A∩B) − n(B∩C) − n(A∩C) + n(A∩B∩C)three sets: subtract the pairs, then add the triple back

Propositions (ประพจน์)

Definition. A proposition is a declarative statement that is definitely either true (T) or false (F), never both and never neither.

"2 + 2 = 4" (T) and "Bangkok is in China" (F) are propositions. These are not: commands ("Close the door!"), open sentences with an unknown ("x > 3"), and opinions ("He is very tall"), because their truth value cannot be decided as written.

Logic inside Python

Python's and, or, not are ∧, ∨, ¬. Implication is not p or q, and ↔ is p == q. Every if statement evaluates a proposition to True or False.

p = True; q = False
print(p and q)      # p ∧ q  -> False
print(p or q)       # p ∨ q  -> True
print(not p or q)   # p → q  -> False   (≡ ¬p ∨ q)
print(p == q)       # p ↔ q  -> False

Truth tables

A truth table lists every combination of T/F for the variables (2ⁿ rows for n variables) and the result of the expression in each row. Pick any expression in Fig. 4 to build its table and see whether it is a tautology.

Key takeawayp → q is false in only one row: p = T and q = F. When p is false the implication is true "vacuously".

Converse, inverse and contrapositive

TypeFormEquivalent to

The key rule is p → q ≡ ¬q → ¬p. When a direct proof is hard, prove the contrapositive instead. The converse is not equivalent: "if it rains, the road is wet" does not mean "if the road is wet, it rained".

The 15 logical equivalence laws

#LawFormula
1Double negation¬(¬p) ≡ p
2Identity (AND)p ∧ T ≡ p · p ∧ F ≡ F
3Identity (OR)p ∨ F ≡ p · p ∨ T ≡ T
4Idempotentp ∧ p ≡ p · p ∨ p ≡ p
5Commutativep ∧ q ≡ q ∧ p · p ∨ q ≡ q ∨ p
6Associative(p ∧ q) ∧ r ≡ p ∧ (q ∧ r) · same for ∨
7Distributivep ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r) · p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)
8De Morgan (AND)¬(p ∧ q) ≡ ¬p ∨ ¬q
9De Morgan (OR)¬(p ∨ q) ≡ ¬p ∧ ¬q
10Absorptionp ∧ (p ∨ q) ≡ p · p ∨ (p ∧ q) ≡ p
11Negationp ∧ ¬p ≡ F · p ∨ ¬p ≡ T
12Implicationp → q ≡ ¬p ∨ q
13Contrapositivep → q ≡ ¬q → ¬p
14Biconditionalp ↔ q ≡ (p → q) ∧ (q → p)
15Exportation(p ∧ q) → r ≡ p → (q → r)

De Morgan's rule in words: to negate, flip AND ↔ OR and negate each part. You can confirm it in the builder with the expression "¬(p ∧ q) ↔ (¬p ∨ ¬q)" (Fig. 4).

Proving tautologies: three methods

MethodHow it worksNote
1 · Truth tableList all 2ⁿ rows; if every row is T it is a tautology.Exhaustive but grows fast: 3 variables = 8 rows, 4 = 16.
2 · SubstitutionApply the 15 laws step by step until the expression becomes T. Name the law at every step.¬(p → q) ≡ ¬(¬p ∨ q) [12] ≡ p ∧ ¬q [9, 1]
3 · Indirect proofAssume the negation is true and derive a contradiction.Also called proof by contradiction.

Quantifiers and their negation

SymbolNameMeaningNegation
∀x P(x)UniversalP(x) holds for every x in the domain∃x ¬P(x)
∃x P(x)ExistentialP(x) holds for at least one x∀x ¬P(x)

To disprove a universal claim you need only one counterexample. To disprove an existential claim you must show that no element works.
