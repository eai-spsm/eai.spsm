Number sets (ระบบจำนวนจริง)

The real numbers are built by nesting larger and larger sets. Each set was invented to hold numbers the previous one could not express: subtraction needed negatives, division needed fractions, and measuring a diagonal needed roots. Knowing which set a number lives in tells you which operations are always allowed on it.

SymbolNameDescriptionExample
ℕNatural numberscounting numbers from 0 (or 1 in some books); no negatives, no fractions0, 1, 2, 3, …
ℤIntegersall whole numbers, positive, negative and zero…, −2, −1, 0, 1, 2, …
ℚRational numbersp/q with p, q ∈ ℤ and q ≠ 0; decimals stop or repeat1/2, −3/4, 0.333…, 7
𝕀Irrational numberscannot be written as p/q; decimals go on forever without repeating√2, π, e, √3
ℝReal numbersevery point on the number line; ℝ = ℚ ∪ 𝕀all of the above

The chain is strict: ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ. The irrationals sit beside ℚ inside ℝ, and the two never overlap: ℚ ∩ 𝕀 = ∅. Pick different numbers in Fig. 1 to see where each one lands, including one that is not real at all.

Watch outA repeating decimal such as 0.333… is rational because it equals 1/3. Only decimals that never repeat are irrational. √9 = 3 is rational even though it has a root sign.

Properties of real numbers

For all a, b, c ∈ ℝ these axioms hold. They are the reason every algebra step is legal, and in a proof you cite them by name.

PropertyAdditionMultiplication
Closurea + b ∈ ℝa · b ∈ ℝ
Commutativea + b = b + aa · b = b · a
Associative(a + b) + c = a + (b + c)(a · b) · c = a · (b · c)
Distributivea · (b + c) = a · b + a · c (links the two operations)
Identitya + 0 = a (0 is the additive identity)a · 1 = a (1 is the multiplicative identity)
Inversea + (−a) = 0a · (1/a) = 1, for a ≠ 0

Ordering

ℝ is an ordered field. For any a, b exactly one of a < b, a = b, a > b is true (trichotomy), and the order is compatible with addition and with multiplication by positive numbers, which keeps inequalities stable.

Absolute value

Definition. |x| is the distance from x to 0 on the number line, so it is never negative. |x| = x when x ≥ 0 and |x| = −x when x < 0.

So |5| = 5, |−5| = −(−5) = 5 and |0| = 0. The minus in the second case does not make the answer negative: x is already negative, so −x is positive.

PropertyStatementNote

Product|xy| = |x||y|
Quotient|x/y| = |x|/|y|y ≠ 0
Triangle inequality|x + y| ≤ |x| + |y|equal when x and y have the same sign
Equation rule|x| = a (a ≥ 0) ⟹ x = a or x = −ano solution if a < 0

Equations and inequalities

To solve |expression| = k with k ≥ 0, split into expression = k and expression = −k, solve both and check. For inequalities the same split gives a single interval for "<" and two outer pieces for ">". Change the relation in Fig. 2 and watch where the V-shape is below or above the grey line.

Interval notation

Interval notation describes a continuous run of real numbers. A round bracket ( ) excludes the endpoint (open); a square bracket [ ] includes it (closed). ∞ and −∞ always get round brackets because infinity is not a number you can reach.

TypeNotationInequalityMeaning
Open(a, b)a < x < bboth endpoints excluded
Closed[a, b]a ≤ x ≤ bboth endpoints included
Half-open[a, b)a ≤ x < bleft included, right excluded
Half-open(a, b]a < x ≤ bleft excluded, right included
Unbounded(a, ∞)x > aeverything above a
Unbounded[a, ∞)x ≥ aa and everything above
Unbounded(−∞, b]x ≤ bb and everything below
Whole line(−∞, ∞)x ∈ ℝno restriction

Intervals combine with union ∪ and intersection ∩. The solution of |x| > 2 is (−∞, −2) ∪ (2, ∞), two separate pieces joined by ∪, while |x| ≤ 2 is the single interval [−2, 2]. Try the same thing in Fig. 2.

Surds and rationalisation

A surd is an irrational root: √n where n is a positive integer that is not a perfect square. √2, √3, √5 are surds; √4 = 2 and √9 = 3 are not, because they are rational. Surds appear whenever you solve a quadratic or use Pythagoras with non-integer sides.

RuleFormulaExample
Product√(ab) = √a · √b (a, b ≥ 0)√12 = √4 · √3 = 2√3
Quotient√(a/b) = √a / √b (b > 0)√(9/4) = 3/2
Square(√a)² = a, √a · √a = a(√5)² = 5
Simplify√(a²b) = a√b (a ≥ 0)√50 = √(25·2) = 5√2

Rationalising the denominator

A fraction with a surd in the denominator is not in simplest form. Multiply top and bottom by the conjugate of the denominator. The conjugate of (a + √b) is (a − √b), and (a + √b)(a − √b) = a² − b is free of roots by the difference of squares. Example: 1/(1 + √2) × (1 − √2)/(1 − √2) = (1 − √2)/(1 − 2) = √2 − 1.

Solving equations: radicals, absolute values and every combination

Once you know the properties of ℝ, the next skill is solving equations. They come in a few families, and the trick is always the same: peel the outermost layer first, split into cases wherever a sign could be lost, and check every candidate at the end, because squaring or splitting can create answers that do not belong.

Without radicals or bars

Linear: collect x on one side. Quadratic: factor, complete the square or use x = (−b ± √(b² − 4ac)) / 2a. The simplest quadratic is x² = k, which gives x = ±√k (two answers if k > 0, one if k = 0, none if k < 0). The "±" is where two cases come from, and it returns in every family below. The number of solutions of a quadratic is explored in the SAT section of Relations & Functions.

Radical equations

StepWhat to doWhy
1 · IsolateGet the radical alone on one side.so that squaring removes it cleanly
2 · SquareSquare both sides: (√A)² = A and (x + r)² = x² + 2rx + r².removes the root, but also allows A = (−B)²
3 · SolveSolve the resulting polynomial equation.gives candidates, not yet answers
4 · CheckPut every candidate back in the original equation. Require the radicand ≥ 0, and the other side ≥ 0 (a square root is never negative).discards extraneous roots

Example: √(x + 7) − 1 = x. Isolate: √(x + 7) = x + 1. Square: x + 7 = x² + 2x + 1, so x² + x − 6 = 0, giving x = 2 or x = −3. Check x = 2: √9 = 3 = 2 + 1 ✓. Check x = −3: √4 = 2 but x + 1 = −2 ✗, so −3 is extraneous. The only solution is x = 2. Try it in Fig. 6: set p = 1, q = 7, r = 1, and watch the hollow dot appear where the root has no match.

Two radicals: √(x + 5) = √(2x − 1) → square both sides → x + 5 = 2x − 1 → x = 6, and both radicands (11 and 11) are non-negative ✓. When a radical equation has two roots on one side, isolate one, square, then isolate the other and square again.

Absolute value equations

The bars measure distance from zero, so |A| = k asks "which numbers are exactly k away?". The number of cases depends on what is on the right-hand side.

FormSplit intoCheck
|A| = k, with k a numberA = k or A = −kk < 0 gives no solution
|A| = |B|A = B or A = −Bnothing: both cases are valid
|A| = B, with B an expressionA = B or A = −Bkeep only answers where B ≥ 0
| |A| − b | = c (bars inside bars)|A| = b + c or |A| = b − c, then each splits againb − c must be ≥ 0 for the second

Example with an expression on the right: |2x − 3| = x + 2. Case 1: 2x − 3 = x + 2 gives x = 5, and x + 2 = 7 ≥ 0 ✓. Case 2: 2x − 3 = −(x + 2) gives 3x = 1, x = 1/3, and x + 2 = 7/3 ≥ 0 ✓. Both work. Change d in Fig. 7 to −4 and both candidates are rejected (the right side becomes negative), so the equation has no solution.

Absolute value inside absolute value

Peel the outer bars first. For | |x − 1| − 3 | = 2 the outer bars give |x − 1| − 3 = 2 or |x − 1| − 3 = −2, so |x − 1| = 5 or |x − 1| = 1. Each of those splits again: x − 1 = ±5 gives x = 6 or −4, and x − 1 = ±1 gives x = 2 or 0. That is four solutions. Use Fig. 8 to see how many appear as c changes: when c = b the second inner equation has the single answer x = a, and when c > b it is impossible.

SAT corner. Read |x − 5| = 3 as "x is 3 units from 5", so x = 2 or 8. Word problems about tolerance, error or temperature range are absolute value inequalities: |measured − target| ≤ tolerance. Extraneous solutions are the classic trap when the right-hand side contains x.

Real numbers on a computer

Python has abs() for absolute value and math.sqrt() for roots, but a computer works with binary floating point, which can only store rational approximations. ℝ has infinite precision; float does not.

import math
print(abs(-7))                 # 7        |−7| = 7
print(math.sqrt(2))            # 1.4142135623730951
print(math.sqrt(2) ** 2)       # 2.0000000000000004  (not exactly 2)
print(math.sqrt(2) ** 2 == 2)  # False

This is not a Python bug. It is how IEEE 754 floating point works in almost every language, and it is why 𝕀 exists only in pure mathematics: every computer lives in ℚ.
