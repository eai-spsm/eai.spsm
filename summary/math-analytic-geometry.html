The Cartesian coordinate system

Analytic geometry puts shapes on a numbered grid so that algebra can describe them. Two perpendicular number lines, the horizontal x-axis and the vertical y-axis, cross at the origin (0, 0). Every point is an ordered pair (x, y): x is the horizontal distance from the origin and y the vertical distance.

The axes cut the plane into four quadrants, numbered I to IV anticlockwise from the upper right. The signs of the coordinates tell you the quadrant. Move the point in Fig. 1 across the axes.

QuadrantxyExample
I++(3, 5)
II−+(−2, 6)
III−−(−4, −1)
IV+−(7, −3)

A point exactly on an axis belongs to no quadrant: (5, 0) is on the x-axis and (0, −3) on the y-axis.

Distance formula

Draw a right triangle whose hypotenuse is the segment AB. The legs are |x₂ − x₁| and |y₂ − y₁|, so Pythagoras gives the distance.

d = √[ (x₂ − x₁)² + (y₂ − y₁)² ]always non-negative; squaring removes any worry about subtraction order

Worked example: A(1, 2) to B(4, 6): d = √(3² + 4²) = √25 = 5, the classic 3-4-5 triangle. Use Fig. 2 with the defaults to see it.

Midpoint formula

The midpoint splits both the horizontal and the vertical distance in half, so its coordinates are just the averages.

M = ( (x₁ + x₂)/2 , (y₁ + y₂)/2 )add the x's and halve; add the y's and halve

Example: A(2, −4) and B(8, 2) give M = (10/2, −2/2) = (5, −1). The grey dot M in Fig. 2 updates as you drag the sliders.

Slope (gradient)

Slope measures steepness and direction: rise over run between any two points on the line. It is the same for every pair of points, so it belongs to the line itself.

m = (y₂ − y₁) / (x₂ − x₁)the absolute value makes the distance positive on either side of the line
CaseSlopeMeaning
Risingm > 0goes up from left to right
Fallingm < 0goes down from left to right
Horizontalm = 0y is constant
Verticalundefinedx is constant, the denominator is 0

Set x₁ = x₂ in Fig. 2 to make a vertical line and see "undefined", then set y₁ = y₂ for a horizontal one.

Equations of a line

There are three standard forms. Each is best for a different situation, and you should be able to convert between all three.

FormEquationUse it when
Slope-intercepty = mx + byou know the slope m and the y-intercept b; easiest to graph
Point-slopey − y₁ = m(x − x₁)you know the slope and one point (x₁, y₁)
StandardAx + By + C = 0exam form; needed for the point-to-line distance

Worked conversion

Line through (1, 3) with slope 2. Point-slope: y − 3 = 2(x − 1). Slope-intercept: y = 2x + 1. Standard: 2x − y + 1 = 0.

import numpy as np, matplotlib.pyplot as plt
m, b = 2, -1                    # y = 2x - 1
x = np.linspace(-3, 3, 100)
plt.plot(x, m*x + b)
plt.grid(True, alpha=.3); plt.show()

Changing m and b redraws the line at once, which is a quick way to build intuition for tilt and position. Do the same with sliders in Fig. 3.

Parallel and perpendicular lines

Slopes tell you the relationship instantly. Parallel lines have the same slope and different intercepts. Perpendicular lines have slopes that are negative reciprocals, so m₁ × m₂ = −1.

RelationshipConditionExample
Parallelm₁ = m₂ and b₁ ≠ b₂y = 2x + 1 and y = 2x − 3
Perpendicularm₁ × m₂ = −1y = 3x and y = −x/3
Coincidentm₁ = m₂ and b₁ = b₂identical equations

A horizontal line (m = 0) is perpendicular to a vertical line (undefined slope) even though the product rule cannot be applied to it.

Systems of two lines: how many solutions?

A pair of linear equations is two lines, and a solution is a point on both. Compare the slopes and intercepts you already know: different slopes mean the lines cross at exactly one point; equal slopes with different intercepts are parallel, so there is no solution; equal slopes and equal intercepts are the same line, so every point on it is a solution (infinitely many). Check this in Fig. 3 by setting m₁ = m₂, then b₁ = b₂.

On the SAT the same idea is asked in algebra form, such as "for what k does the system have no solution?". The answer is the value that makes the slopes equal while the intercepts differ. More on counting solutions, with quadratics and exponentials too, is in SAT: how many solutions? in Relations & Functions.

Distance from a point to a line

The shortest distance from a point to a line is along the perpendicular. For the line Ax + By + C = 0 and the point (x₀, y₀):

d = |Ax₀ + By₀ + C| / √(A² + B²)

The denominator is the length of the normal vector (A, B). Steps: write the line in standard form, read A, B, C, substitute, and keep the exact (surd) value unless told to round.

Worked example: point (3, 4), line 3x + 4y − 10 = 0: d = |9 + 16 − 10| / √25 = 15/5 = 3. These are the diagram defaults, and √(9 + 16) = 5 is another 3-4-5 triple.
