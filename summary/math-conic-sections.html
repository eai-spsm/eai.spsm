Introduction to conics

A conic section (หน้าตัดกรวย) is the curve you get when a flat plane slices a double cone. Tilt the plane and the curve changes between four families. All four fit one algebraic shape, the general second-degree equation Ax² + Bxy + Cy² + Dx + Ey + F = 0, and each has an eccentricity e that measures how far it departs from a circle.

Plane cuts…ShapeEccentricityDescription
perpendicular to the axisCirclee = 0perfectly round
tilted, not through the baseEllipse0 < e < 1less steep than the cone's side
parallel to a slant sideParabolae = 1one open branch
steeper than the sideHyperbolae > 1cuts both nappes: two branches

Eccentricity is e = c/a for an ellipse or hyperbola, where c is the focal distance and a the semi-major (or semi-transverse) axis. For a circle e = 0; for a parabola the focus–directrix definition forces e = 1. So you can name a conic from its e without graphing it. Slide e from 0 to 2.5 in Fig. 1 and watch the circle stretch, open into a parabola, then split into a hyperbola.

Circle (วงกลม)

A circle is the set of all points at the same distance r (the radius) from a fixed point, the centre. With centre (h, k):

(x − h)² + (y − k)² = r²centre at the origin: x² + y² = r²
TermSymbolMeaning
Centre(h, k)fixed midpoint
Radiusr > 0centre to any point on the circle
Diameterd = 2rlongest chord, through the centre
CircumferenceC = 2πrperimeter
AreaA = πr²enclosed region

General form and completing the square

Expanding gives x² + y² + Dx + Ey + F = 0. To go back, group the x terms and y terms and complete the square, adding the same amount to both sides.

StepWorking for x² + y² − 4x + 6y − 3 = 0
Group(x² − 4x) + (y² + 6y) = 3
Complete xx² − 4x + 4 → add 4 to both sides
Complete yy² + 6y + 9 → add 9 to both sides
Standard form(x − 2)² + (y + 3)² = 3 + 4 + 9 = 16
Read offcentre (2, −3), radius √16 = 4
import numpy as np, matplotlib.pyplot as plt
t = np.linspace(0, 2*np.pi, 200)
h, k, r = 2, -1, 4
plt.plot(h + r*np.cos(t), k + r*np.sin(t)); plt.axis('equal'); plt.show()

Parabola (พาราโบลา)

A parabola is the set of points equidistant from a focus F and a directrix line. The distance from the vertex to the focus is c, and also from the vertex to the directrix. The chord through the focus perpendicular to the axis is the latus rectum, of length 4|c|.

Featurey² = 4cx (horizontal axis)x² = 4cy (vertical axis)
Vertex(0, 0)(0, 0)
Focus(c, 0)(0, c)
Directrixx = −cy = −c
Opensright if c > 0, left if c < 0up if c > 0, down if c < 0
Latus rectum4|c|4|c|

With the vertex moved to (h, k): (y − k)² = 4c(x − h) has focus (h + c, k) and directrix x = h − c; (x − h)² = 4c(y − k) has focus (h, k + c) and directrix y = k − c. Try both axes in Fig. 3.

Vertex from the expanded form

For y = ax² + bx + c the vertex is at x = −b/(2a), then y = f(x), and c = 1/(4a). Example: y = 2x² − 8x + 5 gives x = 2, y = −3, vertex (2, −3), c = 1/8.

Ellipse (วงรี)

An ellipse is the set of points whose distances to two foci add up to a constant, 2a. It has a longer major axis (length 2a) and a shorter minor axis (length 2b), with a > b > 0, and the three are tied by c² = a² − b².

Featurex²/a² + y²/b² = 1 (a > b)x²/b² + y²/a² = 1 (a > b)
Major axishorizontal, length 2avertical, length 2a
Vertices(±a, 0)(0, ±a)
Co-vertices(0, ±b)(±b, 0)
Foci(±c, 0)(0, ±c)
Eccentricitye = c/a, 0 < e < 1e = c/a, 0 < e < 1

With the centre at (h, k): (x − h)²/a² + (y − k)²/b² = 1 for a horizontal major axis, and the foci shift to (h ± c, k). Drag the point around the curve in Fig. 4: the two grey segments always add up to the same length.

Worked example x²/25 + y²/9 = 1: a = 5, b = 3, c = √(25 − 9) = 4, foci (±4, 0), vertices (±5, 0), co-vertices (0, ±3), e = 4/5 = 0.8. These are the diagram defaults.

Hyperbola (ไฮเพอร์โบลา)

A hyperbola is the set of points where the difference of distances to two foci is constant, 2a. It has two open branches and two asymptotes: lines the branches approach but never touch. The key relation has a plus: c² = a² + b², so c is always bigger than a.

Featurex²/a² − y²/b² = 1y²/a² − x²/b² = 1
Transverse axishorizontalvertical
Vertices(±a, 0)(0, ±a)
Foci(±c, 0)(0, ±c)
Asymptotesy = ±(b/a)xy = ±(a/b)x
Eccentricitye = c/a > 1e = c/a > 1
Ellipsex²/a² + y²/b² = 1
c² = a² − b²
0 < e < 1, one closed curve, no asymptotes.
Hyperbolax²/a² − y²/b² = 1
c² = a² + b²
e > 1, two open branches, two asymptotes.

Worked example: x²/9 − y²/16 = 1 has a = 3, b = 4, c = 5, vertices (±3, 0), foci (±5, 0), asymptotes y = ±(4/3)x and e = 5/3 ≈ 1.67. These are the diagram defaults.
