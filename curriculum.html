Major Class

What each class teaches. The code is on the Material page.

M.4

Foundations: code, circuits and first robots.

  • 1
    Basic Python

    W01-W11 weekly exercises, terminal ATM final exam, Tkinter study-planner capstone

  • 2
    Basic Circuits, Arduino & GPIO

    Ohm's Law, series/parallel circuits, board & breadboard basics, PWM, servo, ultrasonic, I2C LCD

  • 3
    Physics in Robotics

    ESP32 differential-drive robot, Onshape CAD, Dynamixel motor protocol

  • 4
    LINE Chatbot

    Dialogflow intents, Apps Script webhook, Sheets database, Flex Message cards

M.5

Applied AI: single-board computers and vision.

  • 1
    Raspberry Pi Vision & GPIO Labs

    Hand-tracking, servo control, YOLOv8 object detection

  • 2
    Computer Vision with OpenCV

    Image processing, face & hand detection, YOLO object detection

  • 3
    Deep Learning

    AI vs ML vs DL, neural network anatomy, CNN/RNN/Transformer/LLM, training & evaluation

  • 4
    M.5 Final Project - Mecanum Drive Robot

    4-motor mecanum drive, dead-reckoning guidance, YOLO ball detection

    AI Research
